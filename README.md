<details>
<summary>🔧 Fixing broken trophy/stats images permanently (self-hosting guide)</summary>

<br>

The public `github-readme-stats.vercel.app` and `github-profile-trophy.vercel.app` services are shared by hundreds of thousands of GitHub profiles and periodically hit rate limits or go down — this is a widely reported, ongoing issue on both projects, not something wrong with this README's links. The permanent fix is to deploy your own private copy (free, ~10 minutes):

1. **Fork** [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats) and [ryo-ma/github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) to your own GitHub account.
2. Go to [vercel.com](https://vercel.com), sign in with GitHub, and **import** each forked repo as a new project — Vercel auto-deploys it.
3. In the `github-readme-stats` Vercel project → **Settings → Environment Variables**, add `PAT_1` with a GitHub [personal access token](https://github.com/settings/tokens) (no scopes needed for public data) — this gives you your own API quota instead of sharing one.
4. Replace `github-readme-stats.vercel.app` and `github-profile-trophy.vercel.app` in this README with your own `your-project-name.vercel.app` URLs.

After this, your cards run on your own quota and stop going down when the shared instance gets overloaded.

</details>
